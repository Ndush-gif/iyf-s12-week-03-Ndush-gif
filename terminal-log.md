# Terminal log

## Exercise 1: Basic Navigation
- `pwd`- shows `/c/Users/PC`, the folder location where i am in.
- `ls`- lists contents of the current directory e.g 
`OneDrive/` 
`Pictures/`
 `PrintHood@`
 `Recent@`
`'Saved Games'/`
 `Searches/`
 `SendTo@`
`'Start Menu'@`
 `Templates@`
 `terminal-practice/`
 `Videos/`

- `cd ~/Documents`- navigates to my documents folder.
- `cd ..`- one directory back
- `cd ~`-home directory
- `cd ~/terminal-practice` then `pwd` leads to `/c/Users/PC/terminal-practice`

## Exercise 2: Creating Project Structure

- `mkdir -p my-project/src/css my-project/src/js my-project/src/images my-project/docs my-project/tests` — created the whole folder tree, including parent folders
- `touch my-project/README.md` — created an empty file
- `ls -R my-project` — listed everything inside, including subfolders
