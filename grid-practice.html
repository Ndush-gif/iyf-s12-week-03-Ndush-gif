Getting Started with Crochet

Crochet turns a single strand of yarn into scarves, bags and blankets using just a hook and a few basic stitches. The chain stitch comes first, because every project begins with a row of them.

Beginners usually start with a medium-weight yarn and a 5mm hook. Light colors make it easier to see each stitch. Practice a simple square before you move on to bigger pieces, and be patient, because every crocheter's first rows look uneven.
